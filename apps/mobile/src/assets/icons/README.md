# Shared line icons

These Lucide icons use the public website's 1.8px line treatment and forest
colour (`#254f40`). The SVG files are the editable sources. The 96 × 96 PNGs
are rendered at 24 × 24 logical pixels in both Lynx renderers. Bundled PNGs
avoid the iOS host's missing emoji fonts and native SVG decoder differences.

Icons were exported from the repository's `lucide-react` dependency using
React's `renderToStaticMarkup` and rasterized with Sharp at 4× resolution.
Preserve the adjacent Lucide ISC license when updating them.
