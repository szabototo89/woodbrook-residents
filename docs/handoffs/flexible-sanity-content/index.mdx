## Goal

Keep published community information accessible when editorial dates or categories are incomplete. Retain every record and state missing dates without inventing facts.

## Technical changes

Baseline: `1ee889d26756d20b1176da6325a181cd05dac6f5`. Web implementation: `e0bd06d73d8595caf7f96f820e55d105077466e8`. Mobile compatibility and this handoff follow on the same branch; the PR records the final deployed commit.

| Area                  | Before                                                   | After                                                                                                             | Why                                                           | Code                                                                                  |
| --------------------- | -------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| Content normalization | One invalid category or date aborts the snapshot.        | Categories normalize to supported values or Other; unavailable dates become empty text or absent optional fields. | Keep records without guessing dates.                          | `apps/web/src/features/content/contentSchemas.ts`, `contentDates.ts`                  |
| Diagnostics           | Raw schema errors omit document identity.                | Warnings identify fallback fields; unrecoverable errors identify the document and field.                          | Make content repair actionable.                               | `apps/web/src/features/content/sanityContentSource.ts`                                |
| Date presentation     | Invalid dates can throw during rendering.                | Pages label unavailable dates and disclose missing source review dates.                                           | Render incomplete records truthfully.                         | `contentFormatting.ts`, detail pages, `EventCard.tsx`                                 |
| News sorting          | Missing dates return an unstable numeric comparison.     | Undated news follows dated news in either sort direction.                                                         | Preserve predictable browsing.                                | `contentQueries.ts`, `updates/newsFilters.ts`                                         |
| Event calendars       | Missing dates can break timeline or calendar generation. | Undated events keep their own timeline group and detail page; calendar actions wait for a start date.             | Avoid fabricated calendar entries.                            | `events/eventTimeline.ts`, `AddToCalendarButton.tsx`, `scripts/generate-event-ics.ts` |
| Calendar timestamp    | Calendar creation time uses the source review date.      | Calendar creation time uses the generation time.                                                                  | Source review dates are optional factual metadata.            | `events/eventCalendar.ts`                                                             |
| Mobile compatibility  | The mobile date formatter throws on empty strings.       | It returns Date unavailable while keeping collection and detail records.                                          | Preserve the shared endpoint contract for existing consumers. | `apps/mobile/src/features/content/contentModels.ts`                                   |

No CMS documents or dependencies change. The read-only mobile endpoint shares normalization: required date fields remain strings, with empty text representing unavailable dates. Duplicate identities, broken project relations, invalid stages and waste streams still fail. Mobile changes are limited to date formatting and its regression tests.

## Architecture changes

Woodbrook provides public community information. Its Public website application reads published documents from Sanity Content Lake into one content snapshot, a validated collection of public records. This change relaxes editorial dates and categories within that existing path.
