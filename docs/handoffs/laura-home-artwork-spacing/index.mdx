## Goal

Keep homepage text readable when the artist chooses an opaque photograph. Preserve the stacked phone layout and existing links.

## Technical changes

Baseline: `9ef5c0dbeb6e4526e3c498f05ee3d764c22185dc`. The layout implementation commit is recorded above. This handoff’s completion commit also removes redundant scrolling from the hover test. This is separate from the completed optional-content handoff.

| Area               | Before                                                        | After                                                     | Why                                                      | Code                                                   |
| ------------------ | ------------------------------------------------------------- | --------------------------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------ |
| Hero               | Absolute artwork starts inside the text column                | Normal grid flow allocates two bounded columns with a gap | Rectangular images must not cover text                   | `apps/laura-faichney-web/src/styles.css`               |
| Mural              | Artwork uses viewport offsets while copy uses container width | Image and copy share one grid container                   | Keep both edges in the same coordinate system            | `src/features/site/MuralFeature.tsx`, `src/styles.css` |
| Phone layout       | Copy and image stack                                          | Copy and image still stack with a positive vertical gap   | Preserve narrow-screen reading and links                 | Mobile rules in `src/styles.css`                       |
| Image sizing       | Source hints assume oversized overlapping artwork             | Hints match the allocated columns                         | Avoid requesting oversized responsive images             | `HomePage.tsx`, `MuralFeature.tsx`                     |
| Regression         | No rectangular-artwork separation check                       | Checks 12 widths from 390 to 2560px                       | Cover both reported desktop layouts and breakpoint edges | `tests/e2e/home-artwork-spacing.spec.ts`               |
| Hover verification | An explicit scroll races the hover action’s own scroll        | Let Playwright hover scroll to its target                 | Keep the pointer on the card during its assertion        | `tests/e2e/motion.spec.ts`                             |
