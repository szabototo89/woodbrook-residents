## Technical changes

Baseline: `1bf7f3d` before implementation; compared with implementation commit `be4fc6880f2be8b20cba2a7f7f89fc86fce48526`. The session reuses its existing linked worktree and branch.

| Area                | Before                                    | After                                                                     | Why                                           | Code                                           |
| ------------------- | ----------------------------------------- | ------------------------------------------------------------------------- | --------------------------------------------- | ---------------------------------------------- |

| Maintainer guidance | README describes manual builds.           | README explains automatic releases, manual reruns and required secrets.   | Make deployment repeatable.                   | `apps/forma-studio-web/README.md`              |
