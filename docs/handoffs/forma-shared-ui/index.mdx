## Architecture changes

Forma Studio explains website services and lets prospective customers enquire by email. C4 describes systems (C1), running applications (C2), and responsibilities inside an application (C3). This refactor moves repeated presentation inside the Forma public site into shared React components.

| Level | Change                                                                                                 | Evidence                                                                        |
| ----- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| C1    | Unchanged: the same people and external systems interact with Forma Studio.                            | No service integration or contact destination changes.                          |
| C2    | Unchanged: the public site, static builder, content editor and stores keep their boundaries.           | No package, content-fetching or deployment configuration changes.               |
| C3    | Changed page composition; shared chrome and presentation patterns replace duplicated responsibilities. | Annotated component view below; existing Card and FAQ remain unchanged context. |
