## Goal

Align existing mobile screens with the public website reference at `d06366c`. Include the owner-requested native header fix and preserve existing browsing, filters, source notes and official actions.

## Technical changes

Baseline: `d06366c15c339bf35199723cbaff02e1212a75e6`; implementation commit `31bcb99812819ef4a81e10ad63882498dcc1e76e`.

| Area          | Before                                              | After                                                                | Why                                             | Code                                                                     |
| ------------- | --------------------------------------------------- | -------------------------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------ |
| Identity      | Circular initial and emoji controls                 | Website logo and bundled Lucide line artwork                         | Consistent identity without missing glyphs      | `apps/mobile/src/components/AppHeader.tsx`, `LineIcon.tsx`, `TabBar.tsx` |
| Home          | Generic copy, stock-photo news and inert pager dots | Website coastal introduction, shortcuts and source-linked news panel | Match the website hierarchy                     | `apps/mobile/src/features/home/HomeScreen.tsx`                           |
| Records       | Unrelated coastal images on every news/event record | Text-led rows, date badges and service icons                         | Avoid implying a generic photo depicts a record | `CardFeed.tsx`, `DetailScreen.tsx`                                       |
| Shared theme  | Duplicate compact overrides and heavy sans headings | Paper/forest palette, serif headings, consistent gutters and panels  | Match website visual treatment                  | `apps/mobile/src/styles.css`                                             |
| Native header | CSS environment inset resolves to zero              | Host `safeAreaTop` adds measured padding above header content        | Clear system status area                        | `AppHeader.tsx`, `host-props.d.ts`, `nativeHeaderInset.test.tsx`         |

The body uses the host system sans-serif. Georgia is the native equivalent of the website's Newsreader font. PNG line artwork avoids native SVG decoder and emoji-font differences. The default reactive global-props mode updates the inset when the host publishes new metrics. Content models, API contracts, history, selection and orientation code do not change. Editorial image support remains with issue #19. The title-case Health quick filter still fails to match lowercase published categories; All restores records.
