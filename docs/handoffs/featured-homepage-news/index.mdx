## Goal

Help residents identify an editor-selected local story before scanning recent news. Keep the article's date, source and existing detail link visible.

## Technical changes

Baseline: `0adcbc9c26e0fbf885a04e42a75ce547ce9e2004`. Implementation: `bc3b6bad5580889e04c579b6c93295561850a910`. Merge `d5810b3` also brings in newer local main changes without conflicts.

| Area               | Before                                                         | After                                                                                                       | Why                                            | Code                                                                                               |
| ------------------ | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------- |
| Editorial controls | Featured switch did not affect homepage news.                  | Feature on homepage explains selection; optional featuredUntil sets an end time in Irish time.              | Reuse the article publishing lifecycle.        | `apps/sanity-studio/schemaTypes/update.ts`                                                         |
| Article contract   | Featured boolean only.                                         | Optional expiry passes through GROQ, source mapping and runtime validation.                                 | Preserve old documents without migration.      | `apps/web/src/features/content/{sanityQueries,sanityContentSource,contentSchemas,contentTypes}.ts` |
| Homepage selection | Three newest articles; older picks disappeared before display. | Select newest eligible feature first, then two newest other stories; no feature keeps three recent stories. | Keep editorial priority separate from recency. | `apps/web/src/features/content/contentQueries.ts`                                                  |
| News presentation  | Three equally weighted rows.                                   | One labelled forest card, optional photo and two quieter recent rows.                                       | Establish a clear visual hierarchy.            | `apps/web/src/features/home/{HomeUpdates,HomeFeaturedNews,HomePage}.tsx`, `featured-news.css`      |
| News listing       | Newest first.                                                  | Remains newest first; expiry never unpublishes a story.                                                     | Preserve chronological browsing.               | `getUpdatesFromSnapshot`, `tests/e2e/news-order.spec.ts`                                           |

[Design research](./design-research.md) records twelve primary sources, alternatives and the contract chosen before implementation. The [capability document](../../features/featured-homepage-news.md) records acceptance criteria and editor steps.

Existing featured=true stories become eligible on deployment. No live CMS content was changed. Static output evaluates expiry at build time and needs rebuilding to refresh it; runtime loads evaluate the current time. An open page does not refresh automatically.

## Architecture changes

Woodbrook is a public information hub. Sanity Studio is its editor; Sanity Content Lake stores drafts and published content. The Public website application reads articles into a validated snapshot, selects homepage stories and renders them. The feature extends that existing path without adding a service.

| Level | Change                                                                                                            | Evidence                                            |
| ----- | ----------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| C1    | Unchanged: residents, editors, Woodbrook and Sanity retain their existing roles and system boundaries.            | Existing Studio and Sanity adapter; no new service. |
| C2    | Changed: Studio publishes optional expiry; the website reads it and gives one article priority.                   | C2 diagram and article contract.                    |
| C3    | Changed: adapter carries expiry, selection separates the feature, and news presentation renders a prominent card. | C3 diagram and Technical changes table.             |
