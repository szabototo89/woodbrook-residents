## Goal

Fix the native simulator blocker found while verifying [issue #14](https://github.com/szabototo89/woodbrook-residents/issues/14). The owner explicitly expanded the scope to fix it. This record follows the separate [Sanity backend handoff](/#/mobile-sanity-single-source), whose original native failure remains historical evidence.

## Technical changes

Baseline: `4d9f5d7`. Implementation: `4586d2e`. This handoff is a separate documentation change on the same branch.

| Area             | Before                                          | After                                                 | Why                             | Code                                                     |
| ---------------- | ----------------------------------------------- | ----------------------------------------------------- | ------------------------------- | -------------------------------------------------------- |
| Date labels      | `Intl.DateTimeFormat` throws in native Lynx     | Standard `Date` methods build English labels          | Support hosts without `Intl`    | `apps/mobile/src/features/content/contentModels.ts`      |
| Event times      | Home and event rendering stop on missing `Intl` | Date plus zero-padded local 24-hour time              | Render the existing event views | `readableDateTime`, `HomeScreen`, `getDetailModel`       |
| Invalid values   | Intl throws for invalid dates                   | Explicit `RangeError` remains                         | Avoid broken date copy          | `parseDate`                                              |
| Regression tests | Browser-like test host supplies Intl            | Tests remove Intl and cover visible date/time strings | Reproduce the native runtime    | `apps/mobile/src/__tests__/nativeDateFormatting.test.ts` |

Date parsing and device-local time zone semantics are preserved. No dependency, screen layout, content-selection rule, CMS field, or backend contract changes. Main was merged without rewriting history; its preview cleanup remains intact, with the temporary Worker limitation recorded in its operations guide and inventory note.

## Architecture changes

The Mobile app displays public resident content fetched from the Website asset host. Existing screens request date labels from the shared formatting responsibility. The fix changes that responsibility's runtime dependency while keeping its interface.

| Level | Change                                                           | Evidence                                             |
| ----- | ---------------------------------------------------------------- | ---------------------------------------------------- |
| C1    | Unchanged: residents and editorial systems retain the same roles | Existing Sanity backend context view                 |
| C2    | Unchanged: iOS, browser and backend execution boundaries remain  | Existing Mobile app and Website asset host           |
| C3    | Changed: shared date formatting works without global Intl        | Annotated component view and native regression tests |
