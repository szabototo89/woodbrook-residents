## Architecture

Woodbrook is a public information hub for residents in Shankill. Editors publish content in Sanity; a static build reads and validates that content, generates HTML and navigation data, and Cloudflare serves the generated site. CMS changes reach residents after a successful rebuild.

This change alters source selection and deployment configuration within that existing architecture. `createContentSource` chooses the Sanity adapter by default; the deployment script passes its validated selection into the static build. GitHub's scheduler only invokes a Cloudflare hook, while Cloudflare owns the build environment. As documented in the [Cloudflare Builds API reference](https://developers.cloudflare.com/workers/ci-cd/builds/api-reference/) (accessed 22 October 2026), build variables and runtime Worker variables have separate scopes. Runtime Wrangler settings therefore need no change for the static website.

The dates use the existing `collectionDate` Sanity object schema and existing GROQ projection. No schema, route, UI, container or relationship was added, so this change needs no new C4 diagram.
