## Architecture changes

Woodbrook is a public information hub for residents in Shankill. Editors publish content in Sanity; a static build validates the content, generates HTML and navigation data, and Cloudflare serves the generated website. CMS changes reach residents after a successful rebuild.

| Level | Change                                                                                                                                                                                                                 | Evidence                                                                           |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| C1    | Unchanged: residents, editors, the website, Sanity and Google Sheets already existed; no actor or system boundary was added                                                                                            | Existing content adapters and public routes                                        |
| C2    | Unchanged: the web build and Cloudflare static deployment remain the same applications; the existing Sanity store becomes the default source                                                                           | `apps/web/scripts/build-static.ts`, `wrangler.jsonc`                               |
| C3    | Unchanged: the existing factory still selects an existing adapter; validation, caching and schedule rendering retain their responsibilities and interfaces. Only the default selection and configuration values change | `contentSourceFactory.ts`, `scripts/deploy.ts`, unchanged `verify-static-build.ts` |

The scheduler only invokes a Cloudflare hook, while Cloudflare owns the build environment. As documented in the [Cloudflare Builds API reference](https://developers.cloudflare.com/workers/ci-cd/builds/api-reference/) (accessed 22 October 2026), build variables and runtime Worker variables have separate scopes. Runtime Wrangler settings therefore need no change for the static website. A prose responsibility delta is sufficient for this small source-selection change; no new C4 view was added.
