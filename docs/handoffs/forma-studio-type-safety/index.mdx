## Goal

Prevent unsafe TypeScript from reaching a Forma Studio production build. Cover application code, tests, scripts and configuration while preserving generated files and website behavior.

Baseline: `d3f8147295cc9d99e1376ddf678b7a091fe0330e`. Implementation: `483b78e9176e4df3bc2c2eff294e16d25a0512e3`. This completes the local implementation of [issue #6](https://github.com/szabototo89/woodbrook-residents/issues/6).

`unknown` requires validation before using a value. Type-aware lint uses compiler type information to detect unsafe dependency and platform API results. Its scope is Forma Studio only; no dependencies or other applications' type policies change.

Generated `src/routeTree.gen.ts` is excluded from lint and compiler root-file discovery. Normal imports still resolve it; its existing generated directive controls checking. No generated code or generator configuration changes. Dependency declarations and build output remain excluded.

Negative lint examples use standard input. Compiler fixtures use a temporary directory outside the app and extend its strict configuration; only unrelated ambient type packages are omitted. Temporary build probes are removed in `finally` blocks. No failing fixture is committed in production sources.
