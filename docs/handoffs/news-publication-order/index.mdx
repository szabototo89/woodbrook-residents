## Goal

Show the most recently published news first on the landing page and `/updates`.

## Current state

Both page loaders use one shared publication-date sort before applying their existing collection limits. The homepage selects the three newest articles. Featured flags and spreadsheet row order cannot place older articles first. Equal publication dates retain source order, date-time offsets are compared chronologically, and sorting leaves the source snapshot unchanged.

The recorded HEAD is the session base at handoff authoring. This change requires the site's normal build and deployment to reach production; deployment is outside this request.

## Architecture

The existing content sources and routes are unchanged. `getUpdatesFromSnapshot` in the content query layer copies and sorts validated updates by descending publication timestamp. The homepage selector and News collection loader both call it before truncating their collections.
