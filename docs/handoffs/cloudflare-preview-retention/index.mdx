## Goal

Temporary Cloudflare previews currently stay published until someone removes them by hand. This change adds a daily job that deletes repository-owned Pages preview deployments older than seven days, never touches production, and reports what it scanned, deleted, retained, skipped or failed. The Worker preview gap and the manual dispatch path are documented rather than hidden.

The script validates the inventory, accepts `--config`, `--dry-run` and `--now` for local checks, and paginates Pages deployments at 25 per request. The real API rejected larger page sizes with HTTP 400, so 25 is the tested value. A repeated run selects no candidates because deleted deployments disappear from the listing and a 404 delete is treated as a skip. Credentials are read from environment variables and never written to logs or the summary.

## Architecture changes

Woodbrook is a public information and action hub for Shankill residents. The cleanup job is repository operations automation, not a resident-facing capability: it runs in GitHub Actions, calls the Cloudflare API and changes no application, data store or runtime component.
