# Browseable agent handoffs

Status: ready for review

## Goal

Keep feature context in `woodbrook/docs/handoffs/` and make it readable in a browser. Use an independent viewer and the small template in the repository's `HANDOFF.md`.

## Current state

| Area         | Change                                                                                           |
| ------------ | ------------------------------------------------------------------------------------------------ |
| Guidance     | Root and web AGENTS.md require a feature handoff.                                                |
| Documents    | Each docs/handoffs/feature-slug/index.mdx document and its assets stay in one folder.            |
| Browser      | The independent viewer at 127.0.0.1:3002 lists documents; /#/agent-handoffs opens this document. |
| Architecture | Mermaid renders version-controlled C4 source files and fenced code blocks.                       |

- [x] Keep documents in the repository root.
- [x] Use MDX with tables and task lists.
- [x] Complete verification and visual review.

Decisions: keep the viewer in apps/handoffs, independent of the public website; reuse React and Vite; use MDX, remark-gfm and Mermaid for their existing document and diagram support. Documents are trusted repository code, compiled at build time. This feature adds no editor or upload endpoint.
