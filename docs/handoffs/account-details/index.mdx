## Goal

Let a signed-in Woodbrook resident save, change or remove an optional Eircode and/or exact address. Keep resident locations private and use the existing Firebase account feature flag and free Spark project.

## Technical changes

Baseline: `c41728e`. Verified implementation: `2412d31`, including core feature commit `7635e4e`. Concurrent main `0f94045` was integrated before verification; its Sanity default and stricter handoff contract are preserved and described in their own handoffs. The following delta describes the account feature.

| Area               | Before                                                   | After                                                                                                                                                           | Why                                                                                                       | Code                                                                                                    |

Both fields are optional. Eircode validation checks format only and does not verify a real address or residency. Saving both fields blank or selecting Remove saved location deletes the document; it does not delete the authentication account. Failed writes preserve edits, and failed initial reads prevent editing until retry succeeds. Private data is never placed in URLs or static HTML. The existing `?feature_flag=firebase-auth` or `VITE_FIREBASE_AUTH_ENABLED=true` opt-in controls the entire account feature.

The first default Firestore database in project `woodbrook-auth-20261021` is Standard edition, Native mode, `europe-west1` (Belgium), with `freeTier: true` and point-in-time recovery disabled. No billing upgrade, real resident record migration or Clerk account operation was performed. The browser receives no administrative credential. Firebase administrators retain normal administrative access. See the [capability contract](../../features/account-details.md) for exact scope and CLI commands.

## Architecture changes

Woodbrook is a public information and action hub for residents of Shankill. Firebase Authentication manages sign-in identities; its stable user identifier (UID) is the key for a separate private Cloud Firestore profile. The website runs the editor in the browser and communicates directly with Firebase services over HTTPS. Firestore rules authorize each request using the signed-in identity; Cloudflare continues serving static website assets.
