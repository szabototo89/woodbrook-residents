## Goal

Implement [issue 2](https://github.com/szabototo89/woodbrook-residents/issues/2). Residents can narrow News by category, browse oldest first and share their chosen view.

## Technical changes

Baseline: `9f48f799359269919e670993708eda3c24bbac2c`, after bringing local main into the reused worktree. Implementation: `016a32b9345a0611e8c24a57cd713a34fc7ffe57`.

| Area             | Before                                            | After                                                                                | Why                                                       | Code                                                                      |
| ---------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------- | ------------------------------------------------------------------------- |
| URL state        | News had no filter parameters.                    | Category and sort validate into safe defaults and survive navigation.                | Share and restore a chosen view.                          | `apps/web/src/routes/updates/index.tsx`, `newsFilters.parseNewsParams`    |
| Results          | One featured story and a fixed newest-first grid. | Category filters and oldest/newest ordering apply to all matching articles.          | Find relevant and older stories.                          | `apps/web/src/features/updates/newsFilters.ts`                            |
| Feature          | The feature always preceded the grid.             | The default retains it; changed selections include it once in chronological results. | Preserve editorial defaults and respect sorting.          | `newsFilters.selectNews`                                                  |
| Collection       | News returned at most 25 articles.                | News returns the full published collection with its feature separated.               | Avoid excluding older matching articles before filtering. | `apps/web/src/features/content/contentQueries.ts`                         |
| Controls         | News had no browsing controls or result count.    | Labelled dropdowns, live count, reset and an empty-match message.                    | Make selection and recovery clear.                        | `UpdatesPage.tsx`, `updates.css`                                          |
| Static rendering | News had no saved-filter hydration path.          | Static default HTML hydrates before applying URL selections.                         | Avoid mismatches on bookmarked static pages.              | `UpdatesPage.tsx`, `UpdatesPage.static.test.tsx`, `apps/web/package.json` |

The URL uses `category` from the existing article taxonomy and `sort=newest|oldest`. Invalid values become `all` and `newest`. No dependency, schema or content migration is needed. Static builds use their existing content snapshot; fresh content still needs a rebuild. Loading all published articles increases the News response as its archive grows.

The new handoff title exposed an ambiguous test selector. The handoff browser test in `apps/handoffs/tests/e2e/handoffs.spec.ts` now selects the exact Sort dropdown by role, so document titles cannot match it.

## Architecture changes

Woodbrook is a public information hub for residents. The Public website application reads published articles. News now validates browser selections and filters its complete article collection within that application.

| Level | Change                                                                                                      | Evidence                                   |
| ----- | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| C1    | Unchanged: residents, editors and external systems keep their roles.                                        | No new actor or external integration.      |
| C2    | Unchanged: the website and Studio keep their existing content stores and delivery paths.                    | No new application, store or CMS field.    |
| C3    | Changed: News loads all articles and delegates URL validation and result selection to a new responsibility. | Annotated C3 diagram and `newsFilters.ts`. |
