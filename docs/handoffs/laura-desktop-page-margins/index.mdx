## Goal

Keep the content edges consistent when desktop visitors move between About, Services and Contact. Preserve the existing phone and tablet layout rules.

## Technical changes

Baseline: `023a171ed765421ffb1512d66e83717aafaa80a5`. The implementation commit is recorded above.

| Area            | Before                                        | After                                                                       | Why                                    | Code                                                                                                |
| --------------- | --------------------------------------------- | --------------------------------------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| Desktop margins | Each page sets narrower container widths      | Above 900px, both use the shared 1280px container with 24px minimum gutters | Match About’s content edges            | `apps/laura-faichney-web/src/services-design.css`, `apps/laura-faichney-web/src/contact-design.css` |
| Service list    | An additional 1180px cap shifts rows inward   | Desktop rows use the full shared container                                  | Align services with header and hero    | `services-design.css`                                                                               |
| Hero decoration | Right offsets use the old page widths         | Desktop offsets follow the shared container width                           | Keep artwork at the viewport edge      | Both page stylesheets                                                                               |
| Service images  | Desktop image sizing assumes a narrower row   | Responsive image hints cover the wider service rows                         | Keep source selection appropriate      | `apps/laura-faichney-web/src/features/site/ServicesPage.tsx`                                        |
| Regression      | Reference checks require the old 935px margin | Cross-page checks compare all containers at three desktop widths            | Prevent inconsistent margins returning | `apps/laura-faichney-web/tests/e2e/desktop-page-margins.spec.ts`, `services-design.spec.ts`         |

## Architecture changes

Laura’s website presents the artist’s work and accepts project enquiries. This change adjusts page styling and image size hints; it does not change system boundaries, component responsibilities or interactions. No C4 diagram changes are needed.

| Level | Change                                                                  | Evidence                                         |
| ----- | ----------------------------------------------------------------------- | ------------------------------------------------ |
| C1    | Unchanged: visitors and external services are the same                  | Page styling only                                |
| C2    | Unchanged: the website, content store and enquiry provider are the same | No deployment configuration or data changes      |
| C3    | Unchanged: page and shared component responsibilities remain the same   | CSS width rules and a responsive image hint only |
