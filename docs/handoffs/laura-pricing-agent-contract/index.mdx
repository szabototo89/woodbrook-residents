## Goal

Let a Sanity-connected editing agent discover the full Prices contract without repository access. Preserve existing content and validation behavior.

## Technical changes

Baseline and recorded HEAD before this follow-up: `5ce7312`. The accompanying PR records the implementation commit and final deployments. The reused worktree and branch stay in place.

| Area             | Before                                            | After                                                                | Why                                          | Code                                          |
| ---------------- | ------------------------------------------------- | -------------------------------------------------------------------- | -------------------------------------------- | --------------------------------------------- |
| Schema discovery | Custom validators appear only as opaque markers   | Versioned JSON in `options.agentEditingContract`                     | Expose complete rules to Sanity-only clients | `shared/lauraPricingContract.ts`              |
| Field guidance   | Some required/forbidden combinations are implicit | Every Prices field explains its purpose and constraints              | Make targeted edits understandable           | `apps/laura-studio/schemaTypes/pricesPage.ts` |
| Mode changes     | Agent must infer incompatible values              | Explicit required/unset lists and illustrative examples              | Avoid invalid mixed pricing modes            | `PRICES_AGENT_CONTRACT.modes`                 |
| Safe editing     | Singleton and revision rules live outside schema  | IDs, keys, draft preservation and revision guidance are discoverable | Preserve other edits and correct references  | `PRICES_AGENT_CONTRACT.editing`               |
| Publication      | Schema does not describe static delivery          | Contract separates Sanity publication from verified deployment       | Avoid claiming a publish updated the website | `PRICES_AGENT_CONTRACT.publishing`            |
| Conformance      | No schema-only contract check                     | Serialized metadata examples exercise real validators                | Detect examples or instructions that drift   | `pricesAgentContract.test.ts`                 |

No new content fields or content documents are introduced. The contract sits in schema options and is not included in the public Prices snapshot. Root help points agents to it; individual fields provide concise instructions. Numeric examples are test shapes, not approved rates. <a href={discovery}>The actual Sanity discovery export</a> is retained as evidence. Production `pricesPage` revision `hpf0silrPxAfB7rIgMHb9G` still contains five categories, 15 quote-only options and no numeric pricing fields.
