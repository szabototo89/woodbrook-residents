## Goal

Keep the website usable while the artist publishes partial content. Make all Studio content fields optional without changing visitor enquiry requirements.

## Technical changes

Baseline: `84c49ed3df0b1d26a929ee9cb139a8148c1d039f`. The implementation commit will be recorded after verification.

| Area              | Before                                                                         | After                                                                     | Why                                                                   | Code                                                                 |
| ----------------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Content reader    | Null gallery alt text and order abort the snapshot                             | Absent text, documents, objects and lists normalize to empty values       | Partial publishing must not block every page                          | `apps/laura-faichney-web/scripts/lauraSanitySource.ts`               |
| Ordering          | Numeric order is mandatory                                                     | Explicit order, then creation time, then update time; oldest first        | Support records without manual ordering                               | `displayOrder`, home/gallery timestamp projections                   |
| Partial records   | Every referenced photo must be complete                                        | Skip missing assets, empty collections and records without route slugs    | Keep remaining links and viewers usable                               | `mapGalleryCollection`, `loadHome`, `loadGallery`, `loadServices`    |
| Images and copy   | Components assume every section and image exists                               | Omit absent sections, images and contact links; stretch text-only layouts | Avoid broken images and empty artwork columns                         | `src/features/site`, `src/styles.css`, `scripts/lauraImageAssets.ts` |
| Accessible labels | Artwork alt text must be present                                               | Use collection name plus artwork when missing                             | Keep valid pictures discoverable without inventing image descriptions | `mapGalleryItem`                                                     |
| Studio            | Required validators block partial documents; new records default order to zero | Fields are optional; order has no automatic value                         | Match the website’s optional content contract                         | `apps/laura-studio/schemaTypes`                                      |

Nulls normalize only at the CMS boundary. UI data keeps stable string, object and array shapes; an empty image URL means no usable asset. Supplied malformed types, unsafe announcement URLs and failed network requests still fail visibly. No CMS migration or published document edit is needed. Missing timestamps sort last with stable source order for ties. Incomplete announcements are hidden; incomplete actions are omitted.

## Architecture changes

Laura’s website presents artwork and project enquiries. The build snapshot captures published content before rendering. The Sanity content reader now normalizes missing fields, the image cache skips missing assets, and page components render the remaining content.
